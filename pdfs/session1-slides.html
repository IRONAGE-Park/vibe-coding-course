02 — 코딩의 가치

컴퓨터공학/과학

코딩은 원래부터 누구나 할 수 있었다

AI가 나오기 전에도 생태계의 성장 덕분에 전공하지 않은 사람이 코딩하는 일은 드물지 않았고, 진입장벽은 꾸준히 낮아지고 있었습니다.

컴퓨터공학은 코드 작성 그 이상

소프트웨어를 만들어가는 방법, 여러 사람이 합심해 하나의 프로젝트를 수행하는 방법, 수학적 메커니즘으로 버그 없이 원하는 결과를 만드는 알고리즘을 연구하는 학문으로 변화했습니다.

전공자의 핵심 가치

더 깊고 복잡한 문제를 정의하고 해결하는 것. 단순히 개발만 할 줄 아는 전공자는 일반인과 큰 차이가 없습니다.

02 — 코딩의 가치

생성형 AI(LLM model)와 AI Agent의 등장

코딩을 대신해주는 모델들

ChatGPT와 Claude, 그리고 미국과 중국에서 만들어지는 다양한 모델이 코딩을 해주기 시작했고, 남아 있던 진입장벽을 완전히 허물었습니다.

'코딩을 어떻게 하지?'라는 고민의 소멸

과거 집안 전선이나 전화기를 연결해주던 기술자가 사라진 것처럼, 숙련자의 분야에 초심자가 바로 접근할 수 있는 도구가 생겼습니다.

누구나 손을 뻗을 수 있는 영역으로

셀프 인테리어, 차량 개조, 자가진단 키트가 가능해진 것처럼 — 쉽사리 손댈 수 없었던 프로그램 개발도 이제 직접 손댈 수 있는 영역이 됐습니다.

도구가 아무리 좋아져도, 할 수 있는 것과 없는 것을 구분하는 안목은 사람의 몫입니다

(주)인바이즈
02 — 도구를 보는 안목

컴퓨터는 무얼 할 수 있는가

CAN — 반복과 기억컴퓨터가 잘하는 일

  • 버스 도착 데이터를 매일 같은 규칙으로 수집·정리
  • 축제 후기 수천 건에서 특정 단어를 즉시 검색
  • 조건이 맞는 순간, 24시간 언제든 알림

CANNOT — 발견과 판단컴퓨터가 못하는 일

  • 현장에서 사람들이 겪는 불편을 발견하는 일
  • 두 기능 중 무엇이 더 가치 있는지 결정하는 일
  • 세상에 기록되지 않은 정보를 다루는 일

왼쪽은 AI에게, 오른쪽은 여러분에게 — 오늘 실습의 역할 분담이기도 합니다

(주)인바이즈
02 — 도구를 보는 안목

만들 수 있는게 뭔지 판단하는 기준

기준 1 — 획득컴퓨터가 획득할 수 있는 데이터인가?

O — 획득할 수 있는 데이터

  • 사진 · 영상 · 위치(GPS) · 센서 값
  • 사용자가 직접 입력한 글과 신고
  • 공개된 웹페이지의 일정 · 공고 · 통계

X — 획득할 수 없는 데이터

  • 냄새 · 촉감 같은 감각 정보
  • 사람의 속마음, 기록되지 않은 현장 상황

기준 2 — 가공컴퓨터로 가공할 수 있는 데이터인가?

O — 가공할 수 있는 일

  • 계산 · 통계 · 조건 비교 · 분류
  • 검색 · 요약 · 지도 표시 · 알림

X — 가공으로 해결되지 않는 일

  • 무엇이 더 중요한지에 대한 가치 판단
  • 미래를 확정하는 일 (예측은 오차가 있는 추정)
  • 쓰레기 치우기 같은 물리적 행동

두 질문에 모두 '예'라면 — 만들 수 있습니다. 이제 직접 판단해봅시다

축제·행사 일정 모음 사이트

WHY왜 바로 가능한가

  • 필요한 데이터가 이미 공개되어 있다 — 시청·축제 홈페이지의 일정

  • 팀 벤치마킹 사진·메모 아카이브 페이지

  • 청년 지원사업 마감일 모음 페이지

세 가지 질문을 모두 통과 — 데이터가 있고 · 써도 되고 · 정보 접근 문제를 실제로 해결합니다

SOLVED앱이 해결하는 것

03 — 개발 프로세스

Waterfall / Agile

WATERFALL — 한 번에, 완벽하게요구 분석 → 설계 → 개발 → 테스트 → 배포

  • 소프트웨어를 패키지로 개발하던 시대의 방식
  • 다섯 단계를 한 호흡에, 최초 기획을 거의 완벽하게 구현하는 것이 목표

Waterfall model — Wikimedia Commons · CC BY 3.0

AGILE — 잘게, 자주고객 피드백 중심의 짧은 반복

  • 배포와 업데이트가 간단해지며 도입, 작동 가능한 앱을 빠르게 배포
  • 앱스토어의 앱이 수시로 업데이트되는 이유

Agile 반복 주기 (도식) — cf. Manifesto for Agile Software Development, 2001

AI 등장 전까지는 프로그램의 속성에 따라 두 방법론 중 적절한 것을 택하는 것이 트렌드

바이브 코딩에 어울리는 프로세스는?

일을 '시키는' 사람이란
