## PDF로 내보내는 방법

1. `session1-slides.html`을 **Chrome**에서 연다 (더블클릭 또는 드래그).
2. `Ctrl + P` (인쇄) 실행.
3. 설정:
   - 대상: **PDF로 저장**
   - 여백: **없음**
   - **배경 그래픽** 체크 ✅
4. 저장 → 슬라이드 1장 = PDF 1페이지로 출력됨.
